## Lessons noted

- **`ruff check` is not `ruff format --check`.** During the session I ran `ruff check` after each new file and the `make verify` style suggested both would have caught the issue, but only `ruff format --check src/ tests/ scripts/` flags trailing-whitespace / line-length wraps on new code. The first CI push tripped exactly that gate. Fixed in commit `f39b3c7`; the next push was green. **For future sessions: run `ruff format --check` (or `ruff format` and review the diff) before committing any new module or test file.**
