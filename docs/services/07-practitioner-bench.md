# Practitioner Bench — $10K–$50K/yr

**Duration:** Annual invite-only community membership (12-month commitment)

**Deliverable:** Gated peer community of senior practitioners across Big-4 AI assurance, BigLaw fair-lending / consumer-finance / securities-AI, PE operating partners with AI mandate, and CTO/CAIO peers at top-50 multifamily / Tier-1 financial institutions. Monthly Kunjar Bhaduri-facilitated calls. Private Slack/Discord. First-look at new framework patterns before they go public. Voting input on framework roadmap.

**Target buyer:** Invite-only. Typical members: practicing CTO/CAIO at named-firm tier · Big-4 AI assurance partner or senior manager · BigLaw fair-lending or securities-AI partner · PE operating partner with AI-governance mandate · in-house counsel at top-50 multifamily or Tier-1 financial institution

## What you get

Monthly:

1. **One 90-minute facilitated call** (Kunjar Bhaduri facilitating; 30–60 active participants)
2. **Private Slack/Discord access** — peer-to-peer practitioner discussion; member-led; member-moderated; gated
3. **Discussion-prompt of the month** — Kunjar posts a discussion prompt every month grounded in a current regulatory or framework development; member responses + Kunjar synthesis

Cumulative:

4. **First-look at new framework patterns** — patterns shipping in the next 1–2 versions surfaced to the bench 30–60 days before public release
5. **Voting input on framework roadmap** — bench members vote on the priority ordering of the next 3 patterns / 3 matters / 3 features; results publicly published (the bench's prioritization signal informs but does not determine)
6. **Direct introduction signaling** — members can ping Kunjar for warm introductions to other members; Kunjar facilitates if the introduction shape is appropriate
7. **Exclusive cohort + workshop early access** — bench members receive 30-day priority enrollment + 10% discount on Workshop and Cohort offerings

## Methodology

- Bench membership is invite-only. Application available; Kunjar reviews applications quarterly; acceptance is based on practitioner standing, engagement intent, and current bench composition (each bench cycle balances Big-4 / BigLaw / PE / CTO seats)
- The monthly call cadence is the load-bearing relationship infrastructure
- Member contributions to the bench's collective knowledge feed back into Kunjar's framework evolution

## What's NOT in the public framework

- **Practitioner peer network with consistent membership.** The public framework is consumed alone; the bench is a 30–60 person practitioner peer-network with shared context.
- **First-look access to v.next.** Public framework users see releases when they ship; bench members see patterns in preview 30–60 days earlier.
- **Vote-weighted roadmap input.** The public roadmap is `ROADMAP.md`; the bench's vote influences priority ordering — a signal not available to the public framework user.
- **Warm-intro network.** Bench members can be introduced to each other (subject to mutual interest and Kunjar's discretion) — a relationship-density advantage the public framework cannot provide.
- **Sustained relationship with the author across months.** Bench members get 90 minutes / month of Kunjar Bhaduri's attention — far more than a published framework can offer.

## What's NOT in scope

- 1:1 confidential consulting on member-specific exposure (that's the Diagnostic, Audit, or Retainer; bench members enjoy 10% discount on Audit + Retainer engagements)
- Legal opinion or counsel
- Public framework patterns from the public repo (those remain public; bench members don't get special treatment on what's already shipped)
- Code implementation in member stacks
- Member-to-member commercial transactions (bench is for practitioner discussion, not vendor introduction)
