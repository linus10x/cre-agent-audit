## Methodology

- Anchored on `cre-agent-audit` v0.2.1+ (DOI [10.5281/zenodo.20434575](https://doi.org/10.5281/zenodo.20434575))
- The Regulatory-Incident Replay framework is the running curriculum
- Each matter walkthrough is a hands-on exercise: participants run `cre-replay run <matter_id>` and inspect the generated audit-evidence bundle
- Primary-source citation discipline applied throughout — every regulatory anchor cited verbatim

## What's NOT in the public framework

- **Operator-side judgment-call training.** The public framework documents the patterns; the workshop teaches when to use which pattern, with case studies from confidential engagements (de-identified) that don't appear in the public docs.
- **Live walkthrough of misuse-recognition.** Participants learn to recognize when a vendor-side audit is being mis-sold as operator-side — a recognition skill that requires synthesis the published patterns don't directly teach.
- **Sequence and pacing.** The workshop's hour-by-hour sequence is engineered for retention and behavior-change; the published framework is documentation, not curriculum.
- **Direct access to the author.** Participants get 1-day or 2-day live access to Kunjar Bhaduri — not a written framework, not a recorded course, not a teaching-assistant proxy.
